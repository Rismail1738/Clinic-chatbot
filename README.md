# Clinic Appointment & Symptom Checker Chatbot

A simple healthcare chatbot web application built with Streamlit that allows users to book appointments, check doctor schedules, get basic symptom guidance, and access emergency healthcare contacts.

## Live Demo

https://clinic-chatbot-nbjp5doighgjadnka7z3ko.streamlit.app/

---

## Features

- View available doctors and specialties
- Book clinic appointments
- Get basic symptom advice
- View clinic operating hours
- Access emergency hospital contacts

---

## Technologies Used

- Python
- Streamlit

---

## How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/Rismail1738/clinic-chatbot.git
cd clinic-chatbot
```

### 2. Install Dependencies

```bash
pip install streamlit
```

### 3. Run the App

```bash
streamlit run chatbot.py
```
